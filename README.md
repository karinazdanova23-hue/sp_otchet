# Расписание студии

Веб-приложение для планирования мероприятий, себестоимости, зарплат и аналитики студии.
Хранит все данные в Timeweb S3 — работает одинаково для всей команды, без привязки к Claude.

## Что внутри

- `server.js` — сервер (Express), отдаёт страницу и хранит данные в S3
- `public/index.html` — само приложение
- `package.json` — список зависимостей

## Переменные окружения (задаются в Timeweb, не в коде)

| Переменная | Что это |
|---|---|
| `S3_BUCKET` | имя бакета в Timeweb S3 |
| `S3_ENDPOINT` | адрес S3, например `https://s3.timeweb.cloud` |
| `S3_REGION` | регион, обычно `ru-1` |
| `S3_ACCESS_KEY_ID` | ключ доступа к бакету |
| `S3_SECRET_ACCESS_KEY` | секретный ключ к бакету |

Подробная пошаговая инструкция — в чате, где этот проект был подготовлен.
